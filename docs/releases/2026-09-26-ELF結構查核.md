- ELF 宣告的依賴名稱不等於實際載入版本或部署路徑，不認證供應者，不證明 ROM 與 SDK 同 build，不直接產生 CVE verdict。沒有 dynamic segment 不能推論未靜態整合元件。
- 解析單次讀取最多 2 MiB，program headers 最多 1024、dynamic entries 最多 4096、字串表最多 1 MiB；拒絕超界、未終止或歧義映射，不輸出部分成功結果。
- 盤點最多檢視 128 個來源、12 個 ELF；每來源最多 16 MiB、合計核對最多 64 MiB，解析輸出另有 32000 bytes 預算。超過 metadata 預算顯示 METADATA_LIMIT。受限掃描不代表其他檔案不存在。
- 尚未解 ROM 內任意 ELF、未新增符號／反組譯／呼叫路徑、未讀 section-only dynamic 或 extended program-header count。既有 BuildProof 的 readelf 路徑未替換，本輪不宣稱全站取消原生解析工具。
