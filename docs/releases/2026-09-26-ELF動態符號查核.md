# ELF 動態符號查核

核心 3e4ac49、網頁 3378e2d。成品不只列出 DT_NEEDED 函式庫，也讀取 section-backed 動態符號，保存外部參照、定義名稱、符號類型及連結屬性。這能提供 PC2 的具體成品線索，但不構成呼叫路徑或漏洞適用性證明。

解析依據：[ELF 符號表](https://gabi.xinuos.com/elf/05-symtab.html)、[ELF section 格式](https://gabi.xinuos.com/elf/03-sheader.html)。以未定義 section index 區分外部參照；保留 type／binding，網頁區分函式、物件與弱參照，不把所有符號都說成已呼叫函式。

## 有限範圍

- 支援 ELF32／64、大小端；最多 4096 個 section、單一 dynamic symbol table、16384 個符號、1 MiB 名稱表，與原 metadata 共用 2 MiB 讀取預算。
- 每個名稱最多 1024 bytes，最多保留各 128 個外部參照／定義，保留總數及截短狀態；仍受原整體 metadata 輸出預算限制。
- 無 section table、無 dynamic symbol table、格式異常／超限各自保留狀態；符號解析失敗不丟失已成功取得的架構與依賴資料。
- 不支援透過 dynamic hash table 恢復已移除 section 的符號，不解析符號版本，不反組譯，不追蹤 dlsym 或執行時載入。未列出不能當成未使用 API，出現也不代表執行時呼叫、路徑可達或使用受影響實作。
- 網頁在 PC2 面板下提供動態符號明細；AI 沿用既有 metadata 介面接收並保存線索，沒有新增任意命令或改正式判定。
