# 調查引用提交改善

本次處理前一輪真實 OpenSSL 查核中已發生的格式重試，目的是讓模型把額度用於分析材料。模型維持 `gpt-5.6-sol / high`，整次 token 停止門檻維持 200000，沒有擴大工具權限。

## 修改

- 新模型輸出 schema 明列每項條件文字最多 700 字、產品摘錄最多 1200 字、每條最多四段摘錄及八個引用；多行 Unicode 原文仍可使用。核心仍獨立驗證，不以 schema 取代原文核對。
- 新提交的 REVIEW／REPORT 若已在 `evidence_quotes` 指定 X-ID，核心會把它納入該條件引用，不要求模型在 `citations` 重複列一次。原模型參數照存；新增引用另記 `expanded_quote_citations`，通過全部驗證後才保存條件。沒有新增、猜測或修正引文。
- 未知／跨案件 ID、偽造摘錄、公告當產品證據、數量超限、條件定義改動與真正缺件仍拒絕。歷史紀錄不套用新提交正規化、不改 hash。
- 過長的條件會指出條件 ID 與欄位；提示選用足夠且連續的短公告原文，保留 diff 的空白、符號與換行。

schema 使用官方文件列出的 `pattern` 與 `maxItems`，所有欄位仍 required、object 仍禁止額外欄位；參見 [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses)。格式符合不等於引文語意正確。

## 驗收範圍

採前一輪公開 OpenSSL 1.1.1m 兩份 TEST_ONLY 本機編譯材料：delta 保留舊實作，epsilon 回補官方修補但版本仍為 1.1.1m。兩組都從新工程 run 開始，不使用接續成功的時間作為單輪成績，不新增漏洞輸入或執行攻擊。

此改動不增加正式規則覆蓋，也不解決可信建置來源認證。一般 CVE 的條件解讀仍須覆核；「任意 CVE 都能正確判定成品有／無影響」尚未達標。
