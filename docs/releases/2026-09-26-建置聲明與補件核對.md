## 支援範圍

- 讀取純 JSON 的 in-toto Statement v1／SLSA provenance v1 中 subject 與 resolvedDependencies 的 SHA256，保留來源及完整性核對。
- 名稱或 URI 僅作聲明文字，不跟隨網址、不讀取任意路徑、不執行建置或成品。
- 最多掃描 32 個 JSON 候選，每份不超過 256 KiB，最多四份聲明、每份 32 個參照；同一雜湊最多列八個來源。超出掃描範圍會保留提示。
- 同名檔案雜湊不同、缺少可支援雜湊、格式錯誤、DSSE 封裝未支援及參照超限各自保存狀態。無法辨識的 JSON 不視為有效聲明。
- 未做完整 SLSA schema 驗證、簽章驗證、builder 認證或完整建置輸入證明；沒有 SLSA 等級聲明。即使全部 SHA256 吻合，也不代表原碼確實產生該成品。
