# ROM 成品與 SDK 內容對應

核心 a4880bd、網頁 2de567e。原始 SquashFS ROM 不再只讀版本文字，也能在相同隔離環境內列出有限候選、讀取 ELF，交給既有 ELF 架構／動態依賴解析，並按 SHA256 對照其他交付檔案。沒有執行 ROM、成品或漏洞。

## 範圍與界線

- 限 raw SquashFS；尚未支援廠商容器、分割區偏移及其他檔案系統。
- 保留三個固定版本／套件路徑；額外探查 bin、sbin、usr/bin、usr/sbin 及 lib／usr/lib 中共享函式庫候選。路徑只允許有限字元，拒絕絕對路徑、空段與 `..`，無 shell 拼接。
- 列表最多 2 MiB，最多嘗試六個候選，函式庫名稱優先；每份二進位最多 4 MiB，整個 ROM 共用原有 12 秒期限與收件容量。候選可能是目錄／連結／非 ELF，所以不能保證六次皆取得成品；超限與未讀保留狀態，覆蓋率永遠標有限。
- 仍使用 bwrap 獨立 namespaces、唯讀 ROM／解析器、清除環境與資源界線。未啟用 symlink 跟隨，未增加網路或主機路徑讀取。
- 收據新增 1.1，仍可讀舊 1.0。保存原 ROM、擷取檔案 hash、逐檔狀態；這是內容完整性關聯，不是供應商來源認證。
- ELF 對應最多列八個相同雜湊來源，重查來源 bytes，與原掃描共用 64 MiB hash 預算。相同 bytes 不證明原碼產生成品、實際部署載入或完整建置身分。
- 材料頁顯示擷取 ELF 數量、對應交付檔案及限制。既有 AI 初始材料／保存紀錄沿用 ELF metadata 接線，正式判定不提升。
