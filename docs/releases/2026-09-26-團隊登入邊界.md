# 團隊登入入口的補強

沿用既有 Google OIDC 與受邀帳號白名單，尚未選定或代設公司的登入方式。

- 設定型別、白名單、HTTPS callback、Google metadata 與 client 欄位集中核對；錯誤只顯示固定中文提示，不回顯機密設定。支援子路徑的 `/oauth2callback`。
- 登入狀態必須為布林 true；帳號切換、未登入或拒絕存取時清除 Streamlit 草稿、上傳參照與結果暫存。同帳號正常操作不清除狀態。
- 帳號目錄使用固定 subject 雜湊；拒絕帳號目錄或儲存根目錄的符號連結。這不取代主機權限管理，也不抵禦擁有服務檔案寫入權的人競態修改目錄。
- 原工作台、Google 登入供應者與正式漏洞判定未改。`deploy/requirements.txt` 已列 Authlib；本機一般開發環境未安裝，正式部署仍需用部署依賴。

新增 AppTest 覆蓋未設定、未登入、未受邀與受邀入口，使用合成登入資料確認 workspace 是否被呼叫及指定的帳號路徑；不是實際 OIDC 登入驗收。

實際瀏覽器連到僅監聽 localhost 的臨時 8507 團隊入口，確認只顯示「團隊測試站尚未完成登入設定，暫不開放工作台」，沒有工作台資料或例外。沒有公開端口或設定公司憑證。

待完成：公司登入選型／真實 OIDC 與 HTTPS 部署驗收、認證身分綁定人工覆核、案件分享權限、備份與保留政策。此輪不是正式內網上線或完整安全稽核。
