# 產品片段容量限制

## 修改範圍

AI READ 與初始材料閱讀新增每段 24000 UTF-8 bytes 上限；SEARCH 同樣限制單段，整次回傳原文合計最多 96000 bytes。原有 200 行與檔案讀取限制保留。超大上下文先退回精確命中單行；單行仍過大則保留來源與行號、容量原因，繼續其他檔案。回傳的 X-ID 都對應完整原文行，不裁切後冒充原引用。

COMPARE 逐行累積差異，到 200 行或 24000 bytes 停止，標示 truncated；不是完整 diff。既有 read_excerpt 與 verify_excerpt 保持原語意，避免容量政策讓舊紀錄失去可核對性。網頁／CLI 的直接原文工具仍沿用既有讀取限制，本輪新 READ 上限只接入 AI 與初始材料盤點，不宣稱所有路徑都已限制。

單行超限是工具能力缺口，不能當使用者缺件。提示要求縮小範圍／CAPABILITY_GAP；未新增單行字元範圍閱讀或完整語意驗證。SEARCH 片段省略與檔案掃描涵蓋分開，不把已掃描但未回傳全文的命中說成沒找到。
