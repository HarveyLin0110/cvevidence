## 修正範圍

- 只沿當次 `parent_run_id` 取回原文字及現象；不以 CVE 名称搜尋其他案件。
- 核對 product／release／build／format／CVE，容許同 build DELTA 的新 archive／context。保存的工程 JSON 仍經 hash 與 scope 核對。
- 保留文字 M-ID、原 source context，去除重複項；傳給核心的是未驗文字，舊條件、判定及 review flags 不當成新證據。每次重新取證與判定。
- 最多 32 層、128 筆文字；循環、超限、斷鏈、壞 JSON／hash 或跨範圍時可見地失敗，不能默默截掉歷史繼續判定。歷史讀取與 worker 共用分析期限。
- 從保存紀錄回填「本次調查情境」。使用者本次明確輸入可覆蓋新分析的問題，原 run 不改寫。
- 未改 contracts／核心 CVE 規則／模型設定／AI 保存；不另建 Runner。涉及共享接線，須由負責者審查後整合。
