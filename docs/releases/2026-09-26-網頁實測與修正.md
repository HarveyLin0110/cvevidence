## 發現並修正

1. 情境探索衍生 CVE 原本共用「元件候選探索」選項，無法各自回到最新紀錄。現在依同請求父子關係及 CVE 分組，不靠全域同 CVE 拼接案件。
2. 公開候選大量 JSON 與長原碼占滿頁面。改為先看摘要、命中套件、症狀排序線索、條件與位置；完整 JSON／原文可展開，來源及證據未刪除。
3. CNA 版本欄位為 n/a 時誤顯示精確版本。改為明示結構化版本缺值並直接展示公告摘要，不臆造可比較版本或安全結論。
4. 公開候選刷新後消失。新增不可覆寫查詢收據與 hash 核對，依 run/context 還原；錯案件／損壞收據拒收，失敗不冒充零候選。
5. 展開標題會把檔名底線當 Markdown。標題改用片段編號／行號，完整路徑以純文字保留。
