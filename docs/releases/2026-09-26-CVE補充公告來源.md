# CVE 補充公告來源與讀取範圍

原本只保留 CNA 的前十筆 HTTPS 參考連結，會遺漏 CVE 記錄中 ADP 補上的公告。CVE-2022-48174 的 Debian 維護公告即因此未進入調查。

## 修改

- 公開記錄摘要保留 CNA 與 ADP 連結、容器類型及提供者名稱／組織識別；描述與版本仍取 CNA，不讓 ADP 覆蓋。
- 最多八個 ADP 容器、每容器三十二個參考項目、二十個不重複 HTTPS 連結；達上限明示截短。重複連結保留多個出處。
- 來源政策新增 Debian security／LTS announce 的固定年月／訊息路徑；不開放一般討論區、查詢參數或任意來源。保留 HTTPS、公開位址檢查、固定 DNS 位址連線、不跟隨 redirect、大小與共用期限限制。
- 最多取得三份補充來源、六次下載嘗試，仍共用十五秒上限。失敗不再直接耗盡三份成功來源的配額；未訪問的連結另外列出。
- UI 顯示來源出處、下游公告限制、政策未支援與本輪未訪問來源。下游修補版本不能直接證明產品安全，來源不足不轉成大量使用者補件。
