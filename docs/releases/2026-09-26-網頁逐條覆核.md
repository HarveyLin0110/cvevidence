# 網頁逐條覆核與公司使用範圍

## 本次交付

報告頁可針對選定 AI 紀錄逐條查看條件、原文與行號，填寫支持、排除、矛盾或未確認及理由。保存時核心重新開啟原工程包、核對原文和證據包，再建立獨立不可覆寫的覆核紀錄。重複提交同一識別與相同內容不建立副本；改內容須另建紀錄。

覆核綁定 run、CVE、context、AI payload 與 dossier；跨案件、損壞原文與被改動歷史會拒絕。報告可以選擇附加哪筆覆核或不附加，原工程判定與 AI 紀錄保持不變。

目前覆核者是本機自行填寫的姓名，未連接公司身分認證，不能當成公司簽核。原文一致性核對也不代表自動證明人工判讀正確。

## 公司使用的後續優先順序

使用者確認第一批材料以網通設備 ROM、SDK、SBOM、套件清單與原碼為主，網頁希望放公司內網。舊 Demo_3x3_2026-09-11 僅參考材料組織概念，不匯入其實作或工程資料。

1. ROM 與 SDK／元件／原碼／建置證據的產品版本和同次建置對應；不能把檔名相同或版本命中視為綁定成功。
2. 一般網通材料的辨識與最小補件，區分工具尚不能解析與使用者真的缺材料。
3. 內網登入、案件隔離與權限、覆核者身分、持久工作及備份／保留政策。登入方式待使用者確認；目前仍維持本機服務，尚未宣稱可直接多人部署。
4. 新 CVE 的正式驗證規則、同版 API／CLI 實連比較與工程師品質覆核仍需完成；本次網頁覆核功能不等於上述各項都已完成。
