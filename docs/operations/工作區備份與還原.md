# 工作區備份與還原

這是 Linux／WSL 本機維運指令。備份包含產品材料與調查內容，**未加密**，請放在公司允許且有存取控制的儲存位置。不要提交 Git 或上傳公開服務。

先停止新的收件／分析／補件寫入，待既有工作結束。以下在專案根目錄執行，請自行替換備份檔名；既有檔案或資料夾不會被覆蓋。

```bash
.venv/bin/python scripts/workspace_backup.py create \
  --store var/runtime --output /安全備份位置/cvevidence-日期.zip

.venv/bin/python scripts/workspace_backup.py verify \
  /安全備份位置/cvevidence-日期.zip

.venv/bin/python scripts/workspace_backup.py restore \
  /安全備份位置/cvevidence-日期.zip --destination var/restored-日期
```

`--store` 必須是單一工作區／帳號的資料根目錄，內含 runs、blobs 等，不是整個程式專案或所有帳號的父目錄。還原到新資料夾後，先在獨立測試入口使用該 store_root，檢查請求歷史、工程結果、AI 紀錄與原文讀取，再由維運者決定切換；指令不自動替換現行服務。

備份保存 runs、blobs、requests（含未完成請求的 lock）、ai、condition-reviews、public-discovery、events；只接受已知目錄層級及檔名格式。來源中的非標準檔案／暫存写入、連結、blob 雜湊不符或備份期間變動都會拒絕發布備份，請查明原因後重試。

部署設定、`.env.local`、登入金鑰、temporary、ai-temporary、ai-progress 不納入；但**使用者交付材料本身仍完整保存，可能包含敏感內容**，不是自動去識別化或秘密掃描。進行中的工作不會在還原後自動重跑，也不會新增模型費用。既有未完成請求 lock 保留，不能藉還原繞過重送保護。

限制：最多 100,000 檔、8 GiB 未壓縮資料及 16 MiB 備份清單；建立與還原分段搬移檔案，不需要把整份材料包載入記憶體。備份檔權限 0600、還原工作區根目錄 0700。SHA256 核對保證備份內部內容一致，不是供應商簽章、來源認證或完整應用語意驗證；請用可信來源的備份並做實際還原演練。

還原遇到驗證錯誤時不發布新資料夾；若驗證後最終搬移遇到檔案系統錯誤，會保留部分目標並回報失敗供人工檢查，不自動刪除或覆寫。備份排程、異地保存、加密、保留期限與帳號權限仍須依公司政策配置；本輪未自動部署這些政策。
